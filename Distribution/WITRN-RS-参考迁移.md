## 已迁移到 KM003C 工作台

| WITRN-RS 的做法 | KM003C 工作台中的实现 |
| --- | --- |
| 电压、电流、功率仪表卡 | 保留 KM003C 实时值，并增加最小值、平均值、最大值 |
| 单屏监控与合并波形 | 固定左侧三张仪表卡，中央使用一张 V/A/W 合并图，底部使用全时段缩略导航条；监控页不需要纵向滚动 |
| 图表悬停联动读数 | 鼠标位置显示同一采样点的 V/A/W 浮动表格和三枚对应点，支持固定/取消固定游标 |
| 多量程低信号显示 | 三条曲线分别归一化、分别还原真实刻度；可见范围按 1-2-5 上限调整，低量程自动使用 mV/mA/mW 或 µV/µA/µW 和足够的小数位 |
| 大数据量游标快速定位 | 对按时间排序的实时与离线样本使用二分查找，不再逐点扫描 |
| 大数据量图表保留尖峰 | 按可用像素生成 min/max 时间桶；可选三点中值显示降噪，并以淡色原始包络保留尖峰线索。录制、统计、导出不经过滤波 |
| 图表缩放、平移与一键重置 | 开始录制后从 `00:00:00.0` 全程实时延展；手动平移/缩放时显示距最新时间，可一键或双击恢复。缩略历史渐进压缩但保留桶内极值 |
| 开始、暂停、继续、保存 | 开始时立即写入 Application Support 临时录制；暂停时曲线继续，录制文件、时长和累计量均排除暂停区间；取消保存仍可继续或再次保存 |
| 软件累计能量与容量 | 录制区间显示 `integral |P| dt` 累计能量、累计容量、带方向的净能量；暂停区间不计入，CSV/Parquet 仍保留原 23 列契约 |
| 当前充电协议 | 从 KM003C PD 报文生成类型化状态；只有 Source Capabilities、Request、Accept、PS_RDY 齐全才确认 Fixed/PPS/EPR/AVS，不伪造 QC/VOOC/UFCS 检测 |
| 低功率持续自动暂停 | 默认关闭，可配置 mW 阈值和持续秒数；只暂停录制，可手动继续 |
| 防时间跳变与数据质量 | KM003C 使用设备 sequence 时钟，不用系统墙钟积分；缺点、插值时长、重复/乱序丢弃继续写入质量字段 |
| 深色专业仪器界面与响应式布局 | 沿用 KM003C 工作台既定深色配色与中文字体回退；1280×820 使用完整布局，1024×700 自动压缩卡片和工具栏 |
| 连接并发保护、断线收尾 | 既有类型化连接状态继续负责重试边界；拔线和退出会安全结束录制 |

## KM003C 原本已有、继续保留

- 2、10、50、1000 SPS 四档采样率和 13 种可选曲线指标。
- 主监控图固定显示 V/A/W，其余指标移入“高级分析”，不再挤占日常监控页面。
- CC1、CC2、D+、D-，带符号/绝对电流、功率、容量与能量。
- USB PD wire message 与固件状态联合时间线、SPR/EPR 解码和源筛选。
- 设备离线记录目录、下载、绘图、CSV/Parquet 导出。
- 缺失采样、插值时长、无效序列和数据完整度诊断。
- macOS 11+ Universal App、诊断日志、偏好恢复、ad-hoc 签名与 DMG。

## 有意采用不同实现的部分

- WITRN-RS 使用 Tauri、JavaScript 和 uPlot；KM003C 工作台继续使用现有 Rust/egui，不引入第二套前端运行时。
- WITRN-RS 的合并图可使用多条 Y 轴。KM003C 工作台采用同一张合并图，但三组数据分别归一化，并由蓝/绿/橙三个真实量程格式化器还原 V/A/W 数值，避免数量级不同导致曲线被压扁。
- WITRN-RS 文件不会被当作 KM003C 录制导入；桌面导入严格要求当前 23 列字段、兼容类型和单调时间。
- WITRN 设备协议、固件更新、温度服务、Windows 无边框窗口及设备专用 PD 数据格式不适用于 KM003C，不会伪造入口。
- WITRN-RS 应用代码采用 GPL-3.0；本项目只重新实现公开描述的交互与算法思想，没有复制其源代码，以保持 km003c-rs 的 MIT/Apache-2.0 许可边界。
