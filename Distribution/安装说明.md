# KM003C 工作台 macOS 安装说明

版本：`0.1.0 (5)` · Bundle ID：`com.weixun.km003cworkbench`

当前发布：[`v0.1.0-20261004`](https://github.com/weixunkkkkk/km003c-workbench-macos/releases/tag/v0.1.0-20261004)。日期后缀和同日构建序号只用于区分修订包，录制文件仍保持原有 23 列格式。完整更新与验证范围见 [本次说明](../docs/RELEASE-NOTES-2026-10-04.md)。

本文件已在仓库同步到构建号 5。用户指定的现有 DMG 保持原字节，镜像中附带的说明仍含部分旧版描述；安装该包请优先参考 Release 正文。

## 安装

1. 双击 `KM003C-Workbench-v0.1.0-macOS-universal.dmg`。
2. 将 `KM003C 工作台.app` 拖到 `Applications`。
3. 第一次启动时，如果 macOS 提示“无法验证开发者”，在 Finder 中对 App **右键（或按住 Control 点击）→ 打开 → 打开**。这是首版 ad-hoc 签名的预期提示。
4. 使用支持数据传输的 USB-C 线连接 KM003C，关闭其它可能占用设备的 POWER-Z/USB 工具，再点击“连接设备”。

本包支持 Apple Silicon（arm64）和 Intel（x86_64），要求 macOS 11 或更高版本。不进入 Mac App Store；当前没有 Developer ID 证书，也未进行公证，因此不承诺 Gatekeeper 免提示。

## 使用与排错

- 正常启动不会进入演示模式。仅在终端从 App 内部可执行文件启动并附加 `--demo` 时使用确定性演示数据，界面会显示状态文字和右下角低对比度 `DEMO · 演示数据` 标记。演示模式的偏好、日志和临时录制单独存放在 `~/Library/Application Support/com.weixun.km003cworkbench.demo/`，不会进入正式版的恢复列表，也碰不到正式版的录制。
- macOS 默认跳过 USB reset；遇到协议或鉴权异常时，可在“连接时手动 USB reset（高级）”中启用后重新连接。
- 未插设备时状态会显示“未发现设备”并定时重试；设备被占用或协议错误会停止自动重试，并给出关闭占用程序或重新插拔的建议。
- 顶部录制工具栏支持“开始记录 → 暂停记录 → 继续记录 → 保存录制”。点击开始后立即写入 Application Support 下的临时文件，不先打断操作询问路径；暂停期间仍可观察实时曲线，但该段不会写入文件，也不会进入时长、统计和累计量。
- 在“设置 → 通用 → 皮肤”中切换“工业仪器”和“日系风格”。日系风格使用内置日系角色壁纸铺满工作台，并以半透明深色面板保证测量数据清晰；录制中切换只改变视觉，不会暂停、清空数据或重置游标。工业仪器为默认主题。
- 使用“更多 → 记录管理”管理恢复录制和设备离线记录。离线目录刷新会保留当前选择；导入桌面文件时可返回实时数据，也可以另存不改动原始字节的副本及其元数据。
- 录制中的按钮采用灰底红色描边，录制状态和等宽时长使用红色提示。左侧“录制累计”显示不区分正反方向的“累计能量”（`integral |P| dt`）、累计容量和带方向净能量；保存后仍保留上一段结果，直到开始下一段。小能量会自动使用 `µWh / mWh / Wh`，未开始录制时统计显示 `—`。
- 点击“保存录制”后才选择目标文件。取消不会丢弃临时录制，可继续记录或再次保存；拔线和正常退出会安全结束写入，未指定目标位置的文件保留在 `~/Library/Application Support/com.weixun.km003cworkbench/Recordings/Pending/`，可在设置中查看。
- 待机时左侧电压、电流、功率仪表继续实时更新，主区不绘制波形；点击“开始记录”后才展开 V/A/W 合并图、全部／窗口统计和缩略导航。导入桌面文件或打开设备离线记录时也会进入波形回放。
- 主图提供“全程趋势／细节检查”。全程模式合并显示 U/I/P；细节模式单独查看 U、|I| 或 |P|，使用真实工程单位以及局部、从零或锁定量程。游标读数栏显示真实采样值；“固定游标”可保留读数。锁定量程的越界数据会给出提示。
- 图表下方固定显示“全部／窗口”两行统计，包括有效录制时长、累计容量、累计能量和采样点数，不再悬浮遮挡曲线或时间轴；暂停区间不会进入窗口统计。
- 低电流、低电压或低功率范围会自动切换到 mV/mA/mW 或 µV/µA/µW，并增加小数位，避免真实量程上限显示成 `0.00`。
- 新配置默认原始曲线，可选“叠加趋势”显示五点中值趋势，原始曲线仍可见。旧配置的趋势选择继续读取。游标、统计、录制和导出使用原始采样。实时原始缓存为 100000 点，更早历史只有概览；检查完整历史细节请保存后导入文件。
- 点击“开始记录”后，主图和缩略导航以录制起点作为 `00:00:00.0`。范围菜单可选择“全程”、跟随最近 2 秒／10 秒／30 秒／1 分钟／5 分钟，拖动两端或缩放后可查看任意窗口；界面会显示“距最新”时间，点“回到最新”恢复最近窗口，双击导航条恢复全程。历史使用渐进压缩并保留每个桶的最小/最大值，避免 1000 SPS 短尖峰在缩略图中消失。
- “自动暂停（高级）”可在功率持续低于指定阈值后暂停录制，默认关闭。自动暂停只影响录制文件，实时曲线不会停止，之后可手动继续记录。
- “导入”支持本软件产生的 23 列 CSV/Parquet；缺字段、类型错误或时间乱序会明确拒绝，不会把 WITRN 文件误当成 KM003C 录制。主监控固定为 V/A/W，其余指标在设置中的“高级分析”查看。
- 当前来源决定导出路径：实时采样、设备离线记录和桌面导入文件不会混用统计或导出状态。导入文件的“另存副本”不会覆盖原文件，目标文件或 `.km003c.json` 已存在时会要求重新选择文件名。
- 左侧“当前协议”只有在完整捕获 `Source Capabilities → Request → Accept → PS_RDY` 后才显示 USB PD 固定档、PPS 或 EPR/AVS 已确认合同。仅看到能力声明时显示“等待合同”；没有 PD 报文时显示“协议未确认”和 D+/D−/CC 实测值，不根据 VBUS 误报 QC、VOOC 或 UFCS。点击协议卡可进入完整 PD 时间线。
- “PD 分析”使用独立完整页面展示协议报文和固件 trace，不再占用监控页高度。拔线会停止采集并安全结束录制；重新插入后会回到搜索状态。录制导出支持 CSV 和 Parquet，字段契约保持 23 列不变。
- 会话诊断日志位于：`~/Library/Application Support/com.weixun.km003cworkbench/logs/session.log`。超过 4 MiB 时会在下次启动时改名为 `session.log.1`（只保留一份旧日志）；程序内部出错（panic）也会连同线程和调用栈写进这个日志，反馈问题时附上它即可。
