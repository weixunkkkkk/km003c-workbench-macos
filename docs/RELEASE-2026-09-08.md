# KM003C 工作台 v0.1.0 · 2026-09-08 修订版

## 更新

- 修复窗口被遮挡、最小化或隐藏后，采样接收、累计量和录制提交随界面绘制停顿的问题；改由 eframe `App::logic` 调度。
- 保持单轮消息处理上限，积压时继续调度；隐藏窗口仍可响应单实例唤醒。
- 同步设置页表单、选择卡、恢复记录动作列的布局改进，以及中英文控件对齐。
- 增加工业仪器／日系风格皮肤切换，日系角色壁纸与半透明面板；换肤不改变录制状态。
- 保留 USB/PD 核心、录制恢复格式和 CSV/Parquet 23 列契约。

## 验证与边界

- 格式检查、完整测试、严格 Clippy 通过；新增无 UI 绘制的逻辑回归测试，覆盖累计量、30 秒分段、自动暂停/继续和手动暂停。
- 演示模式最小化、隐藏超过两分钟后仍持续写盘；返回前台可暂停、保存，并通过重新导入校验。
- 真机 50 SPS 后台录制 6 分 42.52 秒、20105 点；随后 USB 设备离线。记录已保存，缺失 21 点，最大采样间隔 440ms。十分钟连续录制、其余三档采样率、锁屏及断线后续录本轮尚未完成验收。
- Universal App（arm64 / x86_64）、DMG 挂载、ad-hoc 签名与 SHA-256 校验通过；尚未进行 Apple 公证。
