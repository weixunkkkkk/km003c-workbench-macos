# KM003C 界面精简与对齐验收

日期：2026-09-19。范围：GUI 组件与操作入口；未修改 USB、PD、积分、录制状态机或 23 列文件格式。

## 改动对照

| 原问题 | 本次实现 |
| --- | --- |
| 顶部语言、皮肤和常用操作拥挤 | 语言、皮肤只在通用设置；窄窗保留录制、采样、计时、离线导入，其余进入更多 |
| 设置卡片说明互相挤压 | 144px 标签列、动态行高、等宽分段选项，当前选项说明单独一行 |
| 设置与文件管理混杂 | 五类设置仅保留配置、设备和诊断；独立记录管理包含恢复与设备离线两页 |
| 恢复记录操作按钮漂移 | 继续96px、查看64px、保存64px，旧文件导入64px，固定右边界 |
| 高级曲线三个下拉拥挤 | 移至高级分析窗口，每条高级图表单独选择 |
| 导出入口不明确 | 根据当前来源分发到实时、设备离线、导入文件；导入文件另存原格式副本 |
| 离线页借用实时完整度 | 按当前来源显示；缺少质量信息时显示未知 |
| 小窗口图表挤掉导航 | 按头部实际高度分配绘图区，预留统计与导航；紧凑仪表栏减少多余间距 |
| 日系弹窗透出底层曲线 | 设置和记录管理使用不透明主题底色，主界面壁纸仍保留 |

设置保留居中、固定导航、固定标题与完成区；仅内容区滚动。按钮文字居中，标签/说明左对齐。实现采用 frontend-design 的固定栅格与数据色语义，未添加装饰色。
