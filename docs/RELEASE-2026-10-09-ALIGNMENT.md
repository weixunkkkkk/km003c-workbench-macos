# KM003C 工作台 v0.1.0 (7) 对齐修订包

日期：2026-10-09。本轮按用户确认的三处对齐建议修改并重新打包；没有替换 `/Applications` 中的 build 6，也没有发布 GitHub Release。

## 改动

- 图表范围、标尺与固定游标控件统一 32px 高、8px 间距；范围控件使用独立的左向布局，避免继承右向布局造成高度错位。紧凑窗口也采用 132px 范围宽度，减少“最近 30 秒”被截短。
- 会话累计改为标签、方向箭头、数字、单位四个独立列；数字右对齐、单位左对齐，方向箭头不挤压数值。计时器在固定右侧区域内右对齐。
- 设置的语言下拉框最多 180px 宽；文字继续左对齐，外层设置卡片宽度不变，皮肤选择布局不变。
- 沿用 frontend-design 的灰阶容器与语义数据色原则，不增加装饰颜色，不改 USB、PD、积分、录制状态机、偏好结构或数据格式。

## 验证

- 累计读数几何回归测试通过：180px / 218px 内容宽度下，不同单位、方向箭头和未知值不会移动数字右边界或单位左边界。
- GUI 测试 137 项通过、4 项忽略；GUI 严格 Clippy、全工作区格式检查和差异空白检查通过。此次只有 GUI 布局与 App 版本变化，未重复执行未改动模块的全工作区测试。
- 第一轮隔离演示窗口截图已确认按钮高度与数字／单位列对齐，录制持续更新；发现范围文案截短后加宽，并重新测试和构建。
